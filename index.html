02 — About

The short version

I care about the parts most people never see — the milliseconds, the semantics, the details that make a site feel inevitable rather than assembled.

I'm Arnique, a web developer focused on the front of the stack and everything that makes it fast. I've built marketing sites, web apps, and tooling for startups and established products — work that has to look good and hold up under real traffic.

My default is simplicity: fewer moving parts, clearer structure, and code that the next person can actually read. When something can be removed without losing meaning, I remove it.
